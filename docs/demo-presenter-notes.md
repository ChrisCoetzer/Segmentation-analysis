# Demo presenter notes following the AI client critique

Opening: We are exploring whether finer customer segmentation identifies more responsive audiences. This benchmark supports a pilot decision, not a universal group count or an approved investment budget.

Slide 1: The segmentation chart compares one selected cluster at each level. Its audience gets smaller as segmentation becomes finer. Values are average incremental outcomes per 10,000 cluster members, not total campaign conversions. In gain mode, the plot shows improvement above broad targeting, while the summary retains the raw cluster average. Frequency charts describe user–campaign pairs and observational associations.

Slide 3: The simulator makes a different comparison: every option advertises to the same 10,000 customers in the displayed scenario, assembling them from ranked clusters. Break-even spending is additional contribution that could cover segmentation costs, not profit or an observed cost. The approximately $63 figure compares 16 with 32 groups. The approximately $1,130 AI example compares 8 with 32 groups.

Slide 4: The current chat is scripted. The wrapper, source-linked answers and Python verification are planned implementation work.

Decision: Substitute client baseline lift and contribution, determine whether these audiences could be implemented, obtain operating-cost estimates, and validate the response in a client pilot before recommending spending.
